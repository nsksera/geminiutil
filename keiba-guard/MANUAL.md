# 馬券配分プランナー 使い方マニュアル

ブラウザだけで動くオフラインの計算ツールです。**「どれが的中しても、掛けたお金より多く
戻るような配分」** を自動計算します。インストール不要・アカウント不要・外部通信なし。

- `keiba-guard/index.html` をブラウザで開くだけで使えます。
- デザインは Apple Human Interface Guidelines 風（ライト／ダーク自動切替）。

---

## 1. 全体の流れ

```
[レース情報]     … 日付・競馬場（中央10場＋地方15場）・レース番号。書き出しファイル名に反映
[予想からの提案] … 1〜3着の候補を入れると打ち方の提案（点数つき）→「追加」で馬券パターン化
[馬券パターン] … 単勝〜3連単 を行（カード）ごとに自由に追加（各行にメモ欄）
[予算]         … 総予算と100円丸めの設定
[配分スタイル] … 安全率スライダーと本命の指定
[結果]         … 入力のたびに自動で計算・更新
[データ]       … 自動保存 / ファイル書き出し / 読み込み
```

入力のたびに**自動で再計算**されます。「配分を計算」ボタンは確認用として残していますが、
普段は押さなくても構いません。

---

## 2. レース情報

一番上のカードで日付・競馬場・レース番号を入力します（どれか1つだけでもOK）。

| 入力 | 内容 |
|---|---|
| 年月日 | 記録したいレース日の日付（未入力の初期値は「本日」） |
| 競馬場 | 中央 10場（札幌〜小倉）＋ 地方 15場（大井・川崎・船橋・浦和・笠松・名古屋・園田・金沢・佐賀 など）のプルダウン |
| レース番号 | 1〜12 |

入力した内容は**保存ファイル名に反映**されます:
`keiba-guard-2026-10-18-Ohi-6.json` のように **半角英数字のみ** で安全な名前になります
（競馬場は英字表記、未入力の部分は名前から省略。カード下に実際の名前を常時表示）。
レース情報は保存・書き出し・読み込みの対象です。

---

## 3. 予想からの提案

着順ごとに馬番を複数選ぶと、打ち方の候補を**点数つき**で提案します。

**入力**: タブ（1着/2着/3着）を切り替えながら、当てはまると思う馬番をタップ。
重複（例: 2着と3着の両方に3番）もOK。「全クリア」で消去。
予想は保存対象で、再読込後も復元されます。

**提案の優先順**（入力内容が変わるたびに再生成）:

| きっかけ | 提案 |
|---|---|
| 1〜3着すべてに候補がある | 3連単 フォーメーション（着順ごとの候補の直積・同馬重複は除外） |
| 1着候補が1頭のとき | 3連単 ながし（軸 → 2・3着いずれか）、馬単/馬連/ワイド ながし |
| 候補全体が3頭以上 | 3連複 ボックス（候補全体から3頭） |
| 1着候補（最大4行） | 単勝 |

各提案の「**追加**」を押すと、その打ち方（券種・まとめ）のカードが
馬券パターンに追加され、メモに組み合わせの例が入ります。
オッズと予算を入れると、ふだんの配分計算に乗ります。

---

## 4. 馬券パターンの入力

「**＋ 馬券を追加**」で新しいカードを追加します。「**＋ 直前を複製**」は、
いちばん下のカードの内容（券種・番号/まとめ・オッズ・メモ）を
そのままコピーした新カードを作ります（似た買い目を量産するときに便利）。
不要になったカードは**右上の ✕** で削除できます（下のカードが滑らかに詰まります）。

### 4.1 券種を選ぶ

カード上部のチップから選択します。もう一度同じチップをタップすると解除（リセット）されます。

| チップ | 確定に必要な選択数 | 番号の種類 |
|---|---|---|
| 単勝 / 複勝 | 1 | 馬番(1〜18) |
| 枠連 / 枠単 | 2 | 枠番(1〜8) |
| 馬連 / ワイド / 馬単 | 2 | 馬番(1〜18) |
| 3連複 / 3連単 | 3 | 馬番(1〜18) |

### 4.2 カード内の3つのタブ

1. **番号** — 1点馬券（順位は押した順）
2. **まとめ** — ボックス／ながし／フォーメーション（2.4で解説）
3. **オッズ** — 電卓型キーでオッズ入力

馬単・枠単・3連単は**押した順に 1着→2着（→3着）** と扱われます。

### 4.3 番号タブのキー操作

| 操作 | 挙動 |
|---|---|
| 番号キー | 選択 / 再タップで選択解除 |
| ⌫ | 直前の選択を1つ外す |
| クリア | 全選択を外す |

**選択数の制限（全券種）**

- 単勝・複勝 → 新しい番号を押すと**選択が置き換わります**（ラジオボタン式）。
- 2点以上の確定型 → 満席の状態で別の番号を押すと**入力を拒否**します。
  キーが揺れて、赤いメッセージ（例: 「枠連は選択 2 までです。⌫や再タップで外してから
  選び直してください。」）が約2秒表示されます。解除してから選び直してください。

### 4.4 まとめタブ（ボックス・ながし・フォーメーション）

券種に応じて「1着/2着/3着」または「組1/組2/組3」のタブが並びます。
組のタブを選んでから馬番キーを押すと、その組に候補が追加／解除されます。

| 組合せ | 作り方 | 例 |
|---|---|---|
| **ボックス** | 組を1つだけ使い、馬（枠）番を2つ以上入れる | 馬連: 組1に `3,5,7` → 3点 |
| **ながし** | 軸側の組に1頭、相手側の組に候補を複数 | 枠連: 組1 `1`、組2 `3,5` → 2点 |
| **フォーメーション** | 各着（各組）に複数候補を自由に入れる | 3連単: 1着 `3,5`、2着 `2,8`、3着 `1` → 4点 |

- **点数は自動計算**され、カード下段にたとえば
  「3連単まとめ 3,5 / 2,8 / 1（4点・最低オッズ ≥ 4倍）」と表示されます。
- 同じ馬が含まれる組合せは自動的に除外されます。
- 馬券の購入単位は**点数 × 1点あたり金額**です。計算エンジンは1点あたり100円単位
  （または丸めオフ時は1円単位）を守ります。
- 「⌫」は今フォーカスしている組の直前候補を、「全クリア」は全組の候補を消します。

### 4.5 オッズタブ（電卓キー）

レイアウトは電卓型です。

```
7 8 9
4 5 6
1 2 3
0 . ⌫
クリア
```

小数可（例: `12.5`）。まとめの券種では**全組合せのうち最も低い（最低）配当倍率**を
入力します。1.0倍以下のオッズは保証計算の対象外です（入力しても行が無効になります）。

---

## 5. 予算カード

- **総予算**: 例 `10,000`（カンマ付きのまま編集しても動作します）
- **100円単位に丸める**: ON で配分は1点あたり100円単位に丸められます。
  OFF にすると理論値（小数あり）で計算します。

---

## 6. 配分スタイル（攻撃配分）

- **オッズ下落率（締切想定）**（0〜80%・5%刻み・**初期値30%**）
  - 「締切までにオッズがこの率で下がる」と想定したときの結果を、
    **下落補正なしと併せて結果カードに表示**します（すべての券種に一律適用）。
  - 表示されるもの:
    - バナーに2つのバッジ: `S = 0.733`（現在）と `下落30%後 = 1.048`（下落想定）
    - 両方 1.000 以下なら緑「成立 — 下落しても保証内」。
      現在だけ成立なら黄「成立 — ただし下落すると保証外」（下落時の払戻・利益も併記）。
    - 各行の「的中時(最悪)」に `（下落想定 ¥…）` を併記。
    - 「最低払戻」行に `下落想定 ¥…・利益…` を併記（利益はマイナス表示あり）。
  - 仕組み: 下落率 d のとき `S' = S ÷ (1 − d/100)`。つまり
    **S が (1 − d/100) 以下のとき、下落しても赤字にならない**（例: 30%なら S ≤ 0.700）。
    配分比は下落しても変わらないため、**買い目の金額は変更不要**です。
  - 下落率0%でバッジ非表示（オフ）。

- **安全率**（0〜100%、5%刻み・初期値100%）
  - 100% … 「どの馬券が的中しても払戻 ≥ 総掛金」の完全回避配分（既定動作）。
  - 下げるほど予算の一部が**本命に集中**し、最悪払戻は下がる代わりに
    本命的中時の払戻が増えます。
  - 例（予算10,000・安全率70%）:
    - 保険 7,000円分 → どの行が的中しても最低 X 円は返る
    - 集中 3,000円分 → 本命中で + (最低オッズ ÷ 点数) × 集中額 が上乗せ
- **本命（集中先）**: ドロップダウンで行を選択。初期値「自動」は
  **もっともオッズの高い行**に集中します。
- 保険部分で丸めにより余った金額は捨てず、**本命の集中額に合流**します
  （下限は同じ、上振れだけ伸びます）。
- α=0% は全額本命集中。本命が外れた場合、掛けた全額を失います。

---

## 7. 結果カードの読み方

| 項目 | 意味 |
|---|---|
| バナー `S = xxx` | すべての行の「最低オッズ ÷ 点数」の逆数合計。**1.000以下**なら全シナリオで赤字回避可能 |
| `¥X × 4点` | まとめ券種の「1点あたり × 組合せの点数」（単票は1金額表示） |
| 的中時(最悪) | その行の最低オッズで的中した場合の払戻 |
| 総掛金 / 端数 | 実際に投じる合計金額。丸めで余った額は「未使用」と表示 |
| 最低払戻 | 全シナリオのうち最低の払戻額 |
| 利益 | 最低払戻 − 総掛金（赤字回避時は0円以上） |

---

## 8. 不成立のとき（S > 1.000）

どの配分でも赤字を避けられない状態です。このとき表示される補助情報:

1. **外すと成立する候補** — どの行を削除すれば成立するかを最大3案提示
   （実効オッズが 低い行を優先して外す提案）。
2. **均衡配分（参考）** — 保険をあきらめ全パターンに理論比で打った場合の
   「どれが的中しても同じ損失」の表示。

まとめの点数を減らす、または最低オッズを見直すと S が下がります。

## 9. よくある質問（FAQ）

**Q. まとめのオッズは1つだけ入力で正確ですか?**
入力したのは**最低オッズ（最悪の組合せの配当）**として扱われるため、
「最悪の的中でも総掛金以上」の保証は正しく計算されます。

**Q. 期待値は配分の仕方で変わりますか?**
変わりません（オッズが示す含意確率の下では、配分に関係なく期待払戻は B÷S で一定）。
配分で選べるのは**リスクの形**（最悪値と最大値のバランス）です。

**Q. 入力内容は保存されますか?**
「データ」カードの**自動保存**が ON なら、この端末に自動保存され、
次回ページを開いたときに復元されます（OFF なら保存されず、閉じると消えます）。
 他の端末へ持ち運ぶときは「書き出す（ファイル）」→「読み込む（ファイル）」を使います。

---

## 10. メモとデータの保存・読込

### 10.1 カードメモ

各馬券カードの下端に1行メモ欄があります（例: 「本命は3連軸」「保険の単勝6」）。
メモは計算に影響せず、保存・書き出しの対象になります。

### 10.2 データカード（結果カードの下）

| 機能 | 説明 |
|---|---|
| 自動保存（この端末） | ON の間、入力のたびにこの端末に保存し、再読込後に復元します |
| 書き出す（ファイル） | 現在の行・オッズ・予算・メモ等を JSON ファイルでダウンロード（ファイル名はレース情報カードが組み立てます） |
| 読み込む（ファイル） | 書き出した JSON を選ぶと内容がまとめて復元されます |

- 保存対象: レース情報（日付・競馬場・レース番号）・予想（1〜3着の候補）・券種・
  番号/まとめ・オッズ・メモ・予算・丸め・安全率
- 自動保存は端末・ブラウザ単位のため、別端末への移動はファイルの書き出し/読み込みを使います
- 読み込めないファイルを選んだ場合は警告が出て、入力内容は変更されません

## 12. 動作環境

- オフライン・サーバー不要。`index.html` をブラウザで開くだけ。
- ライト／ダークは端末設定に連動（`prefers-color-scheme`）。
- 対応: デスクトップ/モバイルの最近のブラウザ（Chrome / Edge / Safari）。

> ※ 本アプリは理論値の参考表示です。オッズは変動し、締切後の最終オッズとは異なります。
> 購入馬券がすべて外れた場合、掛けた全額を失います。返還・控除・特払い等の
> 実際の精算規定とは異なる場合があります。
