これは何?

複数の馬券（単勝〜3連単）を行ごとに自由に登録して、「どれが的中しても、掛けたお金より多く戻る配分」を自動計算するツールです。

たとえば 馬単 4→7 と 馬連ボックス 3,5,7 の2行を作ると、4-7 が来たときも、3・5・7 の組合せが来たときも、合計の払戻が総掛金を下回らないように、それぞれの行にいくらずつ入れるかを出します。当たったシナリオが複数来た場合は払戻が足し算されるのでさらに有利です。

最初の「レース情報」カードに日付・競馬場・レース番号を入れておくと、保存ファイルの名前に反映されます（例: keiba-guard-2026-10-18-Ohi-6.json）。競馬場は中央10場と地方15場から選べます。

ステップ1 — 券種を選ぶ

最初は空のカードが2つ表示されています。カード上部のチップで券種を選びます（もう一度押すと解除）。

チップ選ぶ数キーの種類
単勝 / 複勝1馬番 1〜18
枠連 / 枠単2枠番 1〜8（色つき）
馬連 / ワイド / 馬単2馬番 1〜18
3連複 / 3連単3馬番 1〜18

馬単・枠単・3連単は押した順が 1着→2着（→3着）になります（例: 「5」→「4」で 5→4）。

ステップ2 — 番号キーで入れる

  • 数字をタップ → 選択。必要な数そろえると行が確定します（下の帯に「馬連 3 - 5」のように出ます）。
  • 押した数字をもう一度タップ → 解除。
  • ⌫ 直前の1つを外す ／ クリア 全部外す。
  • 単勝・複勝は1つだけ選び直せる（新しい数字で置き換わります）。
  • 2点以上の券種は満席だとそれ以上選べません。キーが揺れて、赤い説明 （「枠連は選択 2 までです。⌫や再タップで外してから選び直してください。」）が約2秒出ます。 外してから選び直してください。

ステップ3 — 打ち方のバリエーション「まとめ」

2点以上の券種では、タブが「番号 | まとめ | オッズ」の3つになります。ボックス・ながし・フォーメーションをまとめて1行で入力できます。

打ち方作り方例 → 点数
ボックス組を1つだけ使い、2つ以上入れる3連複 組1に 3,5,7,9 → 4点
ながし組1 = 軸1つ、組2 = 相手候補複数枠連 組1「1」、組2「3,5」 → 2点
フォーメーション各着に複数候補を自由に入れる3連単 1着「3,5」・2着「2,8」・3着「1」 → 4点
  • 上部の小さい「1着 / 2着 / 3着」（または「組1 / 組2 / 組3」）タブで入れる場所を切り替えます。
  • 点数は自動計算されます。同じ馬が重なる組合せは自動的に除外されます。
  • 全クリア ですべての組の候補を消します。

便利機能 — 予想からの提案

「1着 = 1番、2着 = 2番か3番のどちらか、3着 = 3番か4番」のように、着順ごとに当てはまると思う馬を複数で予想すると、その予想に合わせた打ち方の提案（点数つき）が出ます。

  • 「1着 / 2着 / 3着」タブを切り替えながら馬番をタップ（同じ馬を複数着に含めてOK）。
  • 提案は 3連単フォーメーション / ながし / 3連複ボックス / 馬単・馬連・ワイドながし / 単勝 を点数つきで表示します。
  • ある提案の 追加 を押すと、その打ち方のカードが馬券パターンに追加されます（オッズだけ入れれば配分計算に乗ります）。
  • 全クリア で予想をすべて消去。予想も保存対象です。

ステップ4 — オッズを入れる

タブ「オッズ」に切り替えると電卓型のキー 789 / 456 / 123 / 0 . ⌫ が出ます。

  • まとめの券種は、全組合せのうち最も低く見込まれる倍率（最低オッズ）を1つだけ入力します。
  • 行がそろうと、点数に応じた「最低オッズ ≥ 点数」のめやすも帯に表示されます。
  • 1.0倍以下のオッズは計算の対象外になります。

ステップ5 — 予算を入れる

「予算」カードの「総予算」に金額（例: 10,000）を入れると、配分がただちに更新されます。丸め（1点あたり100円単位）をONにしておけば、実際の馬券と同じ具合に割れます。

バナーがオレンジ「不成立」なら、どんな配分でも損が避けられない状態です。表示される「外すと成立する候補」（3件まで）と「均衡配分（参考）」をヒントに、行を消すかまとめの点数・オッズを見直します。

慣れてきた人へ — 攻撃配分

「配分スタイル」カードの安全率を100%から下げると、予算の一部が本命に集中します。最悪の払戻は下がる代わりに、本命が来たときの払戻が大きく伸びます。本命はドロップダウンで行を指定（初期値は「自動」＝もっともオッズの高い行）。

  • 安全率70% = 予算70%は保険（どれかが来れば最低額は返る）＋30%は本命集中。
  • 安全率0% = 全額本命集中（本命が来なければ全損）。

消したい・増やしたいとき

  • カード右上の ✕ でその行を消せます（下のカードが滑らかに詰まります）。
  • 最下部の ＋ 馬券を追加 で新しいカードを追加します。
  • ＋ 直前を複製 は、いちばん下のカードの内容をそのままコピーしたカードを作ります（似た買い目を量産するときに便利）。
  • 入力内容は自動保存（データカードで ON のとき）でこの端末に残ります。別の端末へは「書き出す／読み込む」のファイルで持ち運べます。

※ 本アプリは理論値の参考表示です。オッズは変動し、締切後の最終オッズとは異なります。購入馬券がすべて外れた場合、掛けた全額を失います。返還・控除・特払い等の実際の精算規定とは異なる場合があります。
