# mp4-loop-viewer VR版 仕様（mp4-loop-viewer-vr-spec）

PC版（mp4-loop-viewer.html）のVR版。Quest 3S のブラウザで開く WebXR アプリとして作る。
設定JSON（カード構成・回転・カット等）はPC版と共通フォーマットを使い、プレイリストの編集はPC側で行う（VR側は再生専用）。

- 配置先：同じリポジトリ（nsksera/geminiutil）に `mp4-loop-viewer/mp4-loop-viewer-vr.html` として置く（GitHub Pages の HTTPS で配信）。
- 動画ファイル：基本は Quest 本体に置いたファイルをピッカーで選ぶ。NASアクセスは将来候補（必須ではない）。

## 1. 画面（板ポリ）の配置

- 動画プレイヤーは1枚の板ポリ（平面）として扱う。
- **空間固定（ワールド固定）**：首を振っても画面はついてこない。
- 板ポリは **X・Y・Z すべての軸で回転** できる。**拡縮** もできる。
- 操作方法は、最低限の機能が揃うまでは **ボタン操作** でよい（掴んで動かす等の直感操作は後回し）。

## 2. 操作系

- **左コントローラー＝前のカードを再生、右コントローラー＝次のカードを再生**。まずはこれだけ。
- カードの選択・編集UIはVR側に持たない（編集はPC側）。

## 3. 実装の順序

1. **2D再生**：空間固定の板ポリに動画を表示し、カード再生（前後切替）ができる状態。
2. **シークバー** を入れる。
3. **1の残り**：XYZ回転と拡縮のボタン操作を揃える。
4. **立体視**（SBS 3D）。
5. **透過**（パススルー／クロマキー）。

## 4. ファイル

- 基本は Quest 本体のローカルファイル（ピッカー選択）。
- NASにアクセスできると便利（将来候補）。

## 5. 構成

- PC版とは別ファイル（mp4-loop-viewer-vr.html）、同じリポジトリ・同じ Pages 配信。
- 設定JSONはPC版と共通。VR側は読み込みのみ。
